🛡️ Web Log Analyzer and Security Monitoring System

A Python-based web log analysis and security monitoring system designed to analyze web server logs, identify suspicious activity, calculate security risk levels, and present the results through a Flask-based dashboard.

📌 Project Overview

The system processes web server access logs and converts raw log data into meaningful security and performance information.

It analyzes:

- IP addresses
- HTTP requests
- Endpoints
- HTTP status codes
- Response latency
- Failed login attempts
- Request volume
- Security risk levels
- Potential brute-force activity

The analyzed information is stored in an SQLite database and exposed through a Flask web application.

🎯 Objectives

The main objectives of this project are:

1. Analyze web server access logs automatically.
2. Identify frequently active IP addresses.
3. Analyze commonly requested endpoints.
4. Detect failed authentication attempts.
5. Identify possible brute-force attacks.
6. Calculate a security risk score for IP addresses.
7. Categorize IPs into LOW, MEDIUM, and HIGH risk levels.
8. Provide a web-based security monitoring dashboard.

🔍 Main Modules

1. Log Parser

The log parser reads the access log and extracts structured information such as:

- IP address
- HTTP method
- Endpoint/path
- HTTP status code
- Request latency

This converts raw log entries into records that can be analyzed by the rest of the system.

2. Request Analysis

The system calculates:

- Total number of requests
- Total errors
- Error rate
- Average response latency

This helps monitor the general health and performance of the web application.

3. IP Analysis

The system counts requests generated by each IP address.

It identifies the most active IP addresses and helps highlight unusual request activity.

4. Endpoint Analysis

The system groups requests by endpoint and identifies the most frequently accessed paths.

Example:

/login
/products
/orders
/health

5. Failed Login Detection

The system identifies failed authentication attempts by monitoring:

/login
HTTP 401

The number of failed login attempts is grouped by IP address.

6. Brute-Force Detection

If an IP generates repeated failed login attempts, the system flags it as a possible brute-force attack.

Current threshold:

5 or more failed login attempts

7. Security Risk Scoring

The system assigns security points based on suspicious activity.

Current scoring model:

Condition| Points
5+ failed login attempts| +50
More than 10 requests| +20
High error rate| +30

The resulting score is used to classify the IP as:

LOW
MEDIUM
HIGH

8. SQLite Database

Parsed log records are stored in an SQLite database.

The database allows the system to perform SQL-based analysis such as:

- Request counting
- IP grouping
- Endpoint frequency
- Failed login analysis
- Brute-force detection
- Risk calculation

9. Flask API

The Flask application provides endpoints for accessing the analysis results.

Main endpoints:

/
 /stats
 /security
 /dashboard

The API provides structured JSON data to the dashboard.

10. Security Dashboard

The web dashboard provides a centralized view of the system.

It displays:

- Total requests
- Total errors
- Error rate
- Average latency
- Top IP addresses
- Most requested endpoints
- Failed login attempts
- Security risk scores
- Security alerts

The dashboard automatically refreshes the analysis periodically.

📊 Security Monitoring

The project currently focuses on detecting suspicious behavior from web logs rather than performing active attacks or penetration testing.

The system can identify indicators such as:

- Repeated failed authentication
- High request volume
- High error activity
- Suspicious IP behavior
- Potential brute-force activity

▶️ How to Run

1. Clone the repository

git clone https://github.com/Ayan121-code/log-analyzer.git

2. Open the project

cd log-analyzer

3. Install required packages

pip install flask

If machine-learning functionality is enabled:

pip install scikit-learn

4. Run the Flask application

python app.py

5. Open the dashboard

Open the local Flask address shown in the terminal, typically:

http://127.0.0.1:5000/dashboard
